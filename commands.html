⚡ Lula Commands

Everything Lula can do.

Explore the commands available for your Discord server.

🌐 General
/help
Shows the available commands and information about Lula.
/userinfo
Shows information about a Discord member.
/serverinfo
Displays information about the current server.
/membercount
Shows the current member count.
/boosters
Displays the server's current boosters.
⭐ XP & Levels
/rank
View your current level, XP, progress and rank.
/level
Learn how the Lula level system works.
/leaderboard
View the server XP and level leaderboard.
🪙 Economy
/balance
Check your LH Coins balance.
/moneyboard
View the richest members of the server.
/daily
Claim your daily LH Coins reward.
/work
Work and earn LH Coins.
/pay
Send LH Coins to another member.
🎫 Tickets
/ticket
Create a private support ticket.
/closeticket
Close the current ticket.
/add
Add a member to the current ticket.
/remove
Remove a member from the current ticket.
🛡️ Moderation
/clear
Delete messages from a channel.
/kick
Kick a member from the server.
/ban
Ban a member from the server.
/unban
Remove a member's ban.
/mute
Give a member a temporary timeout.
/unmute
Remove a member's timeout.
/warn
Give a warning to a member.
/warnings
View a member's warnings.
/unwarn
Remove a warning from a member.
/slowmode
Configure channel slowmode.
/lock
Lock a channel.
/unlock
Unlock a channel.
/nick
Change a member's nickname.
⚙️ Creator Tools
/creatortools
Open Lula's creator management panel.
/commandstats
View command usage statistics.
/testfunction
Run internal bot tests.
